# Runseal

Runseal commits to an execution intent before a BOT Chain result is accepted. This repository contains the `RunsealRegistry` contract and its Foundry tests.

Testnet deployment and explorer proof: [BOTCHAIN_TESTNET.md](BOTCHAIN_TESTNET.md).

This repository publishes the contract layer only. No public web app URL or mainnet deployment is claimed.

```sh
forge build
forge test
```
